# Dentist-Appointment-Booking-Platform
A full-stack web application designed to simplify the process of booking dental appointments. This platform enables patients to easily schedule visits with dentists while providing clinics with an efficient system to manage appointments, availability, and patient records.
## **Core Features:**
#### Authentication:
 - User Registration (Sign Up)
 - Secure Login System
 - Multi-user role access
## User Roles & Functionalities
####  Admin
 - Manage Services (Add, Update, Delete, View)
 - Manage Doctors
 - Manage Articles
 - Manage Staff Members
 - View patient messages
 - Access Admin Dashboard
#### Staff
 - View appointments
 - Edit appointment details
 - Access patient information
 - Staff Dashboard
#### Patient
 - Book appointments
 - View doctor profiles
 - Explore available services
 - Read dental articles
 - Chat with admin
## Real-Time Chat
 - Implemented using WebSockets
 - Enables instant communication between users and admin
## Dashboards
 - Admin Dashboard for full system control
 - Staff Dashboard for appointment handling
## CRUD Operations
 Fully implemented CRUD functionality for:
  - Doctors
  - Services
  - Articles
  - Staff
## Logout
 - Secure logout functionality for all users
